# 细胞实验计算器

一个单文件、离线可用的细胞实验小工具，手机浏览器打开即用。

**在线使用：** https://chenyu078.github.io/biocalc/

## 三个功能

### 1. 细胞铺板（含分步稀释方案）
输入每孔体积、孔数、每孔细胞数、原液浓度，自动生成**可直接照做的稀释步骤**：

- 自动判断是否需要预稀释（避免出现「每孔 0.2 µL」这种没法取的体积）
- 兼顾移液枪量程（2–20 / 5–200 / 10–1000 / 100–1000 µL）与混合难易
- 支持富余量 0/5/10/20%
- 结果可一键复制成纯文本，发给同事

### 2. 浓度稀释
C₁V₁ = C₂V₂，支持 M / mM / μM 与 L / mL / μL，给出需取原液量与稀释倍数。

### 3. 平板克隆
- **计划接种**：目标克隆数 + 预估形成率 → 每皿接种细胞数与原液体积
- **测形成率**：接种细胞数 + 多皿克隆数 → 形成率、平均克隆数 ± SD、皿间 CV

## 离线使用

下载本仓库的 `index.html` 存到手机或电脑，用浏览器打开即可，无需联网。

> 以本地文件方式打开时，浏览器通常禁用网页存储，历史记录不会保存；在线访问则正常保存。

## 说明

计算逻辑仅供参考，实际实验请结合细胞状态与实验室既有习惯调整。
